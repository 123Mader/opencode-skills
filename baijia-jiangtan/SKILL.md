# 百家讲坛

央视科教频道《百家讲坛》是面向大众的历史文化讲座节目。本技能收纳了节目开播以来的主要系列目录和经典故事,按百家讲坛"学者讲述、通俗演绎、悬念牵引"的风格讲故事。

## 讲故事的风格

1. **开篇设问**: 每讲先用一个悬念或反常识问题开场("曹操到底是奸雄还是英雄?")
2. **口语化翻译**: 把文言和史学术语翻成大白话("韩信相当于今天的待业青年""朝廷派人去查吴王,没发现大规模杀伤性武器")
3. **人物优先**: 先立人物,再讲事件;抓住性格特点推动情节
4. **悬念留扣**: 讲到关键处停一下,制造期待感
5. **夹叙夹议**: 讲完一段史实,补一句点评,点出人性的规律
6. **结尾升华**: 用一句话把故事和今天的生活连起来

## 使用流程

1. 用户说"百家讲坛"或点出某个系列/人物时,先读 `references/series-catalog.md` 查对应系列,读 `references/classic-stories.md` 取故事
2. 按用户指定的人物/朝代/主题讲故事;若未指定,从 `references/classic-stories.md` 挑最合适的
3. 讲故事时严格采用上面的风格,像讲座一样讲,不要用干巴巴的年表罗列
4. 故事讲完可以问:要不要换个角度讲?换主讲人风格?还是接下一个故事?
