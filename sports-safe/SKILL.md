# 运动安全指南 (sports-safe)

权威运动健康与损伤预防查询 Skill：**运动注意事项（按项目）+ 损伤处理 + 红旗征警示 + 最新运动医学文献**。

## 安全边界（最高优先）

1. 本 Skill 只汇总公开权威信息供参考，**不构成医疗诊断**
2. 运动中出现红旗征（胸痛/胸闷、异常呼吸困难、晕厥、畸形等）→ **立即停止运动并就医**（中国急救 120）
3. 慢性病患者（高血压/糖尿病/心脏病等）开始运动前**先咨询医生**，必要时做运动风险评估
4. 急性损伤、疑似骨折脱位、脑震荡 → 制动固定后尽快就医，勿自行处理

## 运动量标准（权威共识）

| 人群 | 建议 |
|------|------|
| 成人 18-64 | 每周 **150-300 分钟中等强度**或 **75-150 分钟大强度**有氧（或组合）+ **每周 2 天以上**肌肉力量训练；限制久坐，用任意强度活动替代 |
| 儿童青少年 6-17 | 每天平均 **60 分钟**中-大强度有氧 + 每周 3 次以上大强度/抗阻/健骨活动 |
| 老年人 65+ | 同上，并加入平衡与力量训练防跌倒；功能受限者仍应进行多组分运动 |
| 孕妇/产后 | 无禁忌时每周 150 分钟中等强度有氧（避免仰卧位大强度、易跌倒项目） |
| 慢病人群 | 需运动风险评估后个体化处方（《临床运动处方实践专家共识2025》），强度循序渐进 |

- 强度参考：最大心率 ≈ 220-年龄；谈话测试（中等强度=能交谈不能唱歌）；RPE 主观感觉 0-10
- 走步：每天 7000-10000 步；快走 ≥100 步/分钟才达中等强度（《运动处方中国专家共识2023》）
- 单次时长：30-50 分钟为宜；低于 30 分钟效果有限，超过 1 小时易疲劳损伤

## 运动三阶段（国家体育总局《全民健身指南》）

1. **准备活动（5-10 分钟）**：快走/慢跑预热 + 动态牵拉，动员心肺肌肉，预防急慢性损伤
2. **基本活动（30-60 分钟）**：有氧/力量/球类/传统健身，按 FITT-VP（频率-强度-时间-方式-总量-进阶）
3. **整理放松（5-10 分钟）**：慢走 + 静态牵拉，促进恢复、缓解延迟性酸痛

## 按项目风险速查（脚本内嵌 23 项）

跑步、游泳、篮球、足球、羽毛球、网球、乒乓球、健身/力量/举重、骑行、滑雪、登山/徒步、跳绳、瑜伽、舞蹈、格斗/拳击、排球、滑板/轮滑、飞盘、健步走。

重点提示：
- **羽毛球/篮球/足球/滑雪**：高损伤风险项目，热身必须充分（≥15 分钟），落地屈膝缓冲
- **健身抗阻**：严禁憋气用力（Valsalva 致血压骤升）；大重量需保护；急性疾病期（感冒发烧腹泻）暂停运动
- **跑步**：周跑量增幅 ≤10%；跑鞋 600-800 公里更换
- **高温运动**：避开正午，补水补盐，出现头晕恶心大汗立即停（防热射病）

## 损伤处理核心原则：PEACE & LOVE（替代旧 RICE）

- **急性期（前 48h）**：保护（Protection）→ 抬高（Elevation）→ 冰敷（每次 15-20 分钟，间隔 ≥2 小时）→ 加压包扎（Compression）→ 停止运动
- **恢复期（48h 后）**：渐进负荷（Load）→ 适度运动（Exercise），配合乐观心态与血供活动促进康复
- 消肿止痛后仍无法负重/畸形/剧痛 → 就医拍片排除骨折

## 红旗征（出现即停、及时就医）

运动中**胸痛/胸闷/心悸、异常呼吸困难、晕厥/意识丧失、关节畸形、无法负重、持续出血、热射病（体温>40℃+意识障碍）、运动性抽搐**。运动中突发意识丧失无呼吸 = 心脏骤停：立即呼救 + 120 + CPR（30:2，100-120 次/分）+ 就近取 AED（每延误 1 分钟存活率降 7-10%）。

## 特殊人群要点

- **儿童**：动作规范与监督；炎热潮湿环境补水、避免持续剧烈运动
- **老年**：防跌倒（平衡+力量）；疫苗照常；胸痛/气促立即停
- **糖尿病**：运动前测血糖、随身带糖防低血糖（头晕心慌出冷汗→立即补糖）；注射胰岛素后注意运动时机
- **高血压**：避免憋气与大重量极限；清晨血压高峰时慎剧烈运动

## 常见问题

- 关键词未命中专项表 → 输出通用安全要点 + 文献检索，可换项目别名（如"撸铁"→"健身"）
