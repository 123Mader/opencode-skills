# 心理预期推断引擎 — 设计说明

> 通过视频聊天持续采集微表情时序变化, 推断对方当前的心理预期 / 心理投射状态, 并在对话中"给出"它。

## 1. 目标

原微表情模块只输出"焦虑指数"。本次升级补上 **心理预期 (psychological expectation)**:
即在情绪/焦虑之外, 推断用户"此刻在心里预期/防御/压抑着什么"。

## 2. 数据流

```
CameraX 30fps
   ↓ YUV→Bitmap→镜像
FaceLandmarker (MediaPipe 468点, GPU)
   ↓ landmarks
MicroExpressionAnalyzer.analyzeFrame()
   → FACS AU 强度 (AU4/12/15/17/23/45)
   → 头部偏航 headYawDeg (鼻尖↔左右脸颊水平偏移 → asin 估角)
   → 眨眼率 blinkRate (2 秒滑窗)
   → 焦虑轨迹 anxietyDelta (前1/3 vs 后1/3)
   ↓ AnalysisResult (每 ~0.5s 一次)
PsychologicalProjection.feed(result, headYaw, blinkRate)
   → 6 秒滑窗 8 维评分
   ↓ Projection(label / confidence / summary / advice / trajectoryNote)
   ├── EmotionDashboardView (视频覆盖层实时显示"心理预期")
   └── EmotionStateHolder (全局持有, 跨模式)
        ↓ ChatFragment 读取
        LLMInference.chat(text, visualContext, projection)
           → CBTFlow.buildProjectionReflection(projection) 注入 prompt
           → 模型生成 "我注意到你似乎…, 是这样吗?" 的试探性镜像反馈
```

## 3. 8 类心理预期 + 评分依据

| 分类 | 标签 | 核心特征 (规则评分) | 心理学依据 |
|------|------|---------------------|-----------|
| ANXIOUS_ANTICIPATION | 焦虑预期 | AU4↑ + AU23↑ + 焦虑轨迹上升 | 持续皱眉+唇收紧→预期负面结果 |
| SUPPRESSED_EMOTION | 情绪压抑 | 微表情突变频繁 但表面焦虑低 | Ekman 微表情泄露 + Matsumoto 抑制研究 |
| COGNITIVE_OVERLOAD | 认知负荷过载 | 眨眼率↑ + AU4↑ + AU17↑ | 眨眼率与认知负荷正相关 (Kramer 1991) |
| POSITIVE_ANTICIPATION | 期待/希望 | AU12↑ + 焦虑低 | 嘴角上扬→期待正向结果 |
| DOUBT | 疑虑/不信任 | AU4 轻微 + AU15↑ (焦虑低时) | 蹙眉+嘴角下压=怀疑 |
| AVOIDANT_DEFENSE | 防御性回避 | 头部偏航大 + AU4 + 焦虑中高 | 视线回避=回避型应对 |
| VOLATILITY | 情绪波动 | 微表情多 + 情绪标签切换频繁 | 表情标签不稳=内在拉扯 |
| CALM_GROUNDED | 平静放松 | 各 AU 低 + 焦虑低 + 微表情少 | 基线稳定态 |

每类输出 0~1 得分; 取最高为当前心理预期, 并按总和归一化得 normalizedConfidence。

## 4. 关键设计取舍

- **规则 + 时序轨迹, 而非端到端 DL**: 当前可用且可解释, 训练数据不足时优于黑盒。路线图保留 CNN+LSTM 替换位。
- **个人基线校准**: MicroExpressionAnalyzer.calibrateBaseline() 用 30s 平静视频建立本人 AU 基线, 后续计算为"相对本人平静态"的偏移, 显著降误报。
- **试探而非断言**: LLM 注入 prompt 明确要求"用'我注意到你似乎…, 是这样吗?'的试探口吻; 用户否认立即尊重其自我描述"。避免把推断当成诊断。
- **非医疗声明**: 仅情绪陪伴参考, 严重情况引导专业帮助 (CBTFlow.isCrisis 已有危机路由)。

## 5. 文件清单

| 文件 | 作用 |
|------|------|
| vision/PsychologicalProjection.kt | ★ 心理预期推断引擎 |
| vision/MicroExpressionAnalyzer.kt | 升级: headYaw/blinkRate/anxietyDelta + 基线校准 + 修除零 |
| vision/EmotionStateHolder.kt | 跨模式状态持有 (视频写 / 聊天读) |
| video/EmotionDashboardView.kt | 覆盖层显示心理预期 |
| video/VideoFragment.kt | 接线 + 修 GlobalScope 泄漏 |
| llm/CBTFlow.kt | buildProjectionReflection() 镜像反馈 prompt |
| llm/LLMInference.kt | chat() 接收 projection 注入 |
| chat/ChatFragment.kt | 读取 EmotionStateHolder 喂入对话 |
