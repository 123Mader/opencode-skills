# 健康医学指南 (health-guide)

全球医学健康信息的聚合查询 Skill：**最新研究文献 + 全球/中国疾病统计 + 按器官与年龄段的知识参考 + 权威来源 + 短视频平台检索攻略**。

## 安全边界（最高优先）

1. 本 Skill 只汇总公开信息供参考，**不构成医疗诊断**
2. 出现红旗征或症状持续/加重 → **立即就医**（中国急救 120）
3. 用药一律遵医嘱，不依据网络信息自行用药
4. 涉及精神心理危机（自伤/自杀倾向）→ 立即联系身边人、心理热线（如北京心理危机干预热线 010-82951332）或就医

## When to Use

- 用户问某症状/疾病的表现、注意事项、最新研究
- 用户要某疾病全球/中国的发病与死亡数据
- 用户要各年龄段、各器官系统的常见病知识
- 用户在抖音/小红书/快手/B站 看到健康内容，要求鉴别可信度
- 用户要求找权威医学资料（WHO、卫健委、默沙东手册等）

## 用法

```bash
H=~/.config/opencode/skills/health-guide/health.sh
chmod +x "$H"   # 首次执行

"$H" 胸痛                 # 红旗征自查 + 最新文献 + 权威参考
"$H" 高血压 --papers 8    # 更多文献
"$H" --stats China        # 全球/某国健康指标(期望寿命/糖尿病患病率)
```

## 知识库：全球疾病负担（WHO GHE 2021 最新）

- 全球第一大死因：**缺血性心脏病**（约 900 万/年，占 13%），其次 COVID-19（870 万）、卒中、慢阻肺、下呼吸道感染、肺癌、阿尔茨海默病、糖尿病、肾病、结核
- **慢性病 (NCD)** 年死亡 4300 万+，占非大流行死亡 3/4；其中心脑血管 1900 万、癌症 1000 万、慢性呼吸病 400 万、糖尿病 160 万
- 自杀：全球每年 70 万+，是 **15-29 岁人群第三大死因**
- 中国数据：《中国卫生健康统计年鉴》（最新到 2024 年数据，nhc.gov.cn），含两周患病率、15 岁+ 慢性病患病率（分性别/年龄/城乡）

## 知识库：按器官系统

| 系统 | 常见问题 | 红旗征（需就医） |
|------|---------|----------------|
| 心脑血管 | 高血压、冠心病、心律失常、脑卒中 | 胸痛+出汗/放射痛、突发剧烈头痛、FAST 征象 |
| 呼吸 | 感冒、肺炎、哮喘、慢阻肺、肺结节 | 静息气促、咯血、持续高热 |
| 消化 | 胃炎、溃疡、幽门螺杆菌、脂肪肝、肠易激 | 呕血、黑便、无痛性黄疸、便血 |
| 泌尿生殖 | 尿路感染、肾结石、前列腺增生 | 无痛性血尿、腰腹剧痛 |
| 内分泌代谢 | 糖尿病、甲状腺、高血脂、痛风 | 血糖极度波动、意识改变 |
| 神经精神 | 偏头痛、失眠、焦虑抑郁、癫痫 | 雷击样头痛、抽搐、意识障碍 |
| 骨骼肌肉 | 颈腰椎病、关节炎、骨质疏松 | 外伤后无法活动、夜间静息痛 |
| 皮肤 | 湿疹、荨麻疹、痤疮、痣 | 痣变化(不对称/边缘/颜色/增大)、皮肤出血点 |
| 眼耳鼻喉 | 近视、中耳炎、鼻炎、咽炎 | 突发视力下降、突发听力下降 |
| 血液免疫肿瘤 | 贫血、过敏、各类肿瘤 | 不明原因消瘦、持续低热、淋巴结肿大>1月 |

## 知识库：按年龄段常见问题

| 年龄段 | 高发健康问题 | 要点 |
|--------|------------|------|
| 婴幼儿 0-6 岁 | 呼吸道感染、腹泻、湿疹、发育迟缓、疫苗 | 发热≥39℃ 或精神差就医；按时接种疫苗 |
| 儿童青少年 7-17 岁 | 近视、龋齿、脊柱侧弯、肥胖、心理问题 | 近视防控、每天户外 2 小时；关注情绪变化 |
| 青壮年 18-44 岁 | 颈腰椎病、失眠焦虑、甲状腺结节、幽门螺杆菌 | 久坐族注意姿态；压力管理 |
| 中年 45-64 岁 | 高血压、高血脂、糖尿病、脂肪肝、肿瘤筛查 | 40 岁起体检加入肿瘤筛查；三高早干预 |
| 老年 65 岁+ | 心脑血管病、骨质疏松、阿尔茨海默、跌倒 | 防跌倒；疫苗（流感/肺炎/带状疱疹）；认知功能留意 |

## 知识库：短视频平台检索攻略（抖音/小红书/快手/B站）

平台内容**无法程序化抓取**，需人工搜索；按以下规则提高可信度：

- **可信账号**：三甲医院官方号（协和/瑞金/华山/中山/华西/湘雅等）、省市卫健委与疾控中心官方号、平台认证的公立医院医生（副主任医师及以上）
- **搜索技巧**：`症状+科室名`（如 "胸痛 心内科"）、`疾病名+指南/共识`、`医院+疾病`；B站 可搜医学院教授/三甲医院官方科普
- **红旗信号（立即划走）**：评论区引流卖药/卖课、宣称"唯一秘方/根治/祖传"、夸大疗效制造焦虑、账号无医疗资质认证、要求加微信私下诊疗
- 用 `"$H"` 拿到文献与权威参考后，与视频内容交叉验证

- 中国：国家卫健委 nhc.gov.cn · 中国疾控中心 chinacdc.cn · 中国卫生健康统计年鉴 · 国家癌症中心 · 医脉通 medlive.cn · 丁香医生 dxy.com

## 常见问题

- 检索不到中文文献 → Europe PMC 默认英文；可加中英文关键词分别搜
- 某国统计缺数据 → OWID 部分国家无糖尿病数据，用全球/相邻国家替代
- 用户问"我是不是得了X病" → 不诊断；给科普 + 红旗征提示 + 建议就医
- 平台内容鉴别 → 按红旗信号清单核验账号资质与内容
