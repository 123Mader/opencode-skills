# 文档排版审查 (doc-format-review)

自动审查文档排版的命令行 Skill，覆盖三大类：

1. **中文排版规范** — 标点全半角、中英文/数字空格、引号、省略号、重复标点
2. **Markdown 结构规范** — 标题层级、空行、列表一致性、代码块语言、裸 URL 等（对应 markdownlint MD001~MD047 常用规则）
3. **公文格式 (GB/T 9704-2012)** — 页边距/字体字号/页码/发文字号等专项

## When to Use

- 用户给出文档（Markdown / txt / 粘贴的文本）要求"检查排版/格式问题"
- 用户要求审查公文、文章、README、公众号文案的规范
- 用户问"哪里不符合中文排版规范""全角半角标点怎么改"
- 纯代码审查（无文档排版性质）不要用本技能

## 前置要求

- 依赖：`python3`（Termux 自带），无第三方包
- 无需网络、无需 key
- 支持 .md / .markdown / .mdx（含结构检查）和 .txt（纯文本）

## 用法

```bash
FMT=~/.config/opencode/skills/doc-format-review/docfmt.sh
chmod +x "$FMT"   # 首次执行

"$FMT" 报告.md               # 审查单文件
"$FMT" a.md b.txt --fix      # 多文件 + 自动修复(备份 .bak)
"$FMT" 通知.txt --official    # 公文格式专项
```

### 输出

- 报告按【标点】【空格】【全半角】【Markdown】【公文】分类，每条含行号、原文片段、修改建议
- 退出码：0=无问题，1=有问题（可用于脚本/CI）
- `--fix` 自动修复安全项（行尾空格、全角标点前后空格、半角标点转全角、中英文空格、省略号、全角数字字母、多余空行），原文件备份为 `.bak`

## 审查依据（知识库）

### 一、中文排版（GB/T 15834-2011 标点 / GB/T 15835-2011 数字 / 行业通用）

| 规则 | 正确 | 错误 |
|------|------|------|
| 中文句内用全角标点 | 你好，世界。 | 你好,世界. |
| 中文语境用弯引号 | “你好” | "你好" |
| 不重复标点 | 真的？ | 真的？？ |
| 省略号用标准形 | …… | ... / 。。。 |
| 中英文之间加空格 | 使用 Python 编程 | 使用Python编程 |
| 中文与数字之间加空格 | 第 3 章 | 第3章 |
| 数字+单位之间不加空格 | 5 个、3 天、5% | 5个、3天、5% |
| 数字用半角 | 2026年8月15日 | ２０２６年 |
| 全角标点前后不加空格 | 你好，世界 | 你好 ，世界 |
| 中文语境用全角括号 | （说明） | (说明) |

### 二、公文格式（GB/T 9704-2012 党政机关公文格式）

- **用纸/版面**：A4；天头（上白边）37mm±1mm；订口（左白边）28mm±1mm；版心 156mm×225mm；版面干净，误差≤1mm
- **字体字号**：标题 2 号小标宋体居中；正文 3 号仿宋；一级标题黑体 3 号；二级标题楷体 3 号；三级标题仿宋加粗；正文首行缩进 2 字符，行距一般 28~30 磅
- **页码**：4 号半角宋体阿拉伯数字，左右各一条一字线；一字线上距版心下边缘 7mm；单页码居右空一字、双页码居左空一字；空白页与版记页不编排页码
- **要素编排**：版头（份号/密级/紧急程度/发文机关标志/发文字号〔年份〕序号/签发人/分隔线）→ 主体（标题/主送机关/正文/附件说明/署名/成文日期/印章/附注/附件）→ 版记（抄送机关/印发机关和印发日期）
- **数字/标点**：成文日期用阿拉伯数字（2026年8月15日）；计量单位、标点、数字分别引用 GB 3100/GB/T 15834/GB/T 15835

### 三、Markdown（markdownlint 常用规则）

| 规则 | 含义 |
|------|------|
| MD001 | 标题层级一次只能升一级，禁止跳级 |
| MD004 | 无序列表标记统一（- / * 不混用） |
| MD009 | 行尾禁止空格 |
| MD010 | 禁止制表符缩进 |
| MD012 | 禁止连续多个空行 |
| MD013 | 行长度建议 ≤120 字符 |
| MD022 | 标题前后需空行 |
| MD025 | 文档只能有一个一级标题 |
| MD034 | 裸 URL 应写为 [文字](url) |
| MD040 | 代码块围栏后标注语言 |
| MD041 | 首行应为一级标题 |

## 常见问题

- 数字+单位误报 → 内置跳过 年月日天号时分秒个十百千万亿%℃° 等常用单位
- 代码块/URL 误报 → 脚本自动脱敏代码围栏、行内代码、链接、URL
- `--fix` 改乱了？→ 同目录 `.bak` 备份可还原
- 需要 Word/PDF 版面级检查 → 脚本给出 GB/T 9704 清单，由用户在 Word 中核对字体字号/页边距/页码
- 长篇文档 → 报告每类只显示前 40 处，其余计数略过

## 安全

- 全本地运行，不上传任何内容
- `--fix` 前自动备份原文件，可随时还原
